Shared Window V1

A product pivot from virtual camera output to a normal macOS window that users can select in screen-share pickers.

Recommended branch: feature/shared-window-output

Goal: keep the core CursorFollow behavior, but replace the CoreMediaIO camera extension surface with a visible, shareable output window.

Requirements User-visible behavior, scope, constraints, acceptance criteria, and risk areas for the shared-window product direction. Implementation Plan Phased engineering plan for building the output window, rendering pipeline, controls, and validation flow.

Architecture Shift

The previous ambition was to appear as CursorFollow Camera in camera menus. Shared Window V1 instead presents a real app window, such as CursorFollow Output, that the user shares from Zoom, Meet, Slack, Teams, or other conferencing tools.

This keeps the useful capture and tracking work while removing the extension discovery, signing, IPC, and camera-client compatibility burden.
